# Mini-CS-Student Webpage

A simple, responsive personal webpage created for a college assignment. It showcases essential student information, such as name, course, and academic details, with a clean and minimalistic design.

## Features
- Displays personal information, including name, course, and other details
- Responsive design for a user-friendly experience across devices
- Basic layout with HTML and CSS

## Technologies Used
- **HTML**: Structure of the webpage
- **CSS**: Styling and layout
